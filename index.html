🔐 Учебный пример шифрования RSA

1. Генерация ключей

Выбираем простые числа:

  • p = 3
  • q = 5

Вычисляем:

  • n = p × q = 15
  • φ(n) = (p−1)(q−1) = 2 × 4 = 8

Выбираем e = 3 (взаимно простое с 8).

Находим d, такое что (e × d) mod φ(n) = 1 → d = 3.

Открытый ключ: (n, e) = (15, 3)
Закрытый ключ: (n, d) = (15, 3)
⚠️ В этом примере e = d — это допустимо для обучения, но небезопасно в реальных системах!

2. Шифрование

Сообщение: m = 2 (например, «анализ готов»)

Условия: 0 < m < n и НОД(m, n) = 1 → выполнены.

Шифруем: C = me mod n = 23 mod 15 = 8

→ Шифротекст: C = 8

3. Расшифровка

Расшифровываем: M = Cd mod n = 83 mod 15 = 512 mod 15 = 2

→ Исходное сообщение восстановлено! ✅

Решение шифров Цезаря

1. Определение ключа по парам «открытый текст – шифротекст»

а. АПЕЛЬСИН → САЦЬНВЩЮ

Ключ: k = 18

б. АБРИКОС → ЫЬЛГЕЙМ

Ключ: k = 28

2. Расшифровка сообщений с неизвестным ключом (0 < k < 32)

а. ФХНЗКЧ → при k = 21: КОДИРО (возможно, «КОДИРОВКА» усечена)

б. ЦЩЕБФ → при k = 21: ХРАНИ

3. Шифрование фамилии «ФИРСОВА» с ключом k = 10

Открытый текст: ФИРСОВА

Шифротекст: ЧЫБЧУЖК

Все вычисления выполнены в алфавите русского языка (32 буквы, без «Ё»).
